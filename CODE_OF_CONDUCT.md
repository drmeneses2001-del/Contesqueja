# Código de Conducta 🤝

## Nuestro compromiso

Nos comprometemos a proporcionar un ambiente amigable, seguro y acogedor para todos, independientemente de:

- Género, identidad de género o expresión
- Orientación sexual
- Discapacidades (visibles o invisibles)
- Apariencia física, tamaño corporal o edad
- Raza, etnia o nacionalidad
- Religión o creencias
- Nivel de experiencia, educación o estatus socioeconómico
- Posición política

## Nuestros estándares

### ✅ Comportamientos que fomentamos

- Usar lenguaje **acogedor e inclusivo**
- Respetar diferentes **puntos de vista y experiencias**
- Aceptar **crítica constructiva** con gracia
- Enfocarse en lo que es **mejor para la comunidad**
- Mostrar **empatía** hacia otros miembros

### ❌ Comportamientos inaceptables

- Uso de lenguaje o imágenes **sexualizadas** o discriminatorias
- **Trolling**, comentarios insultantes o despectivos
- **Acoso** público o privado
- Publicar información personal de otros sin consentimiento
- Cualquier conducta que pueda considerarse **inapropiada** en un entorno profesional

## Aplicación

Las violaciones del Código de Conducta pueden ser reportadas abriendo un Issue (si es seguro) o contactando a los mantenedores. Todas las quejas serán revisadas e investigadas.

Los mantenedores tienen el derecho y la responsabilidad de:
- Elimutar comentarios, commits, código o issues que violen este código
- Banear temporal o permanentemente a usuarios con conductas inaceptables

## Alcance

Este Código de Conducta aplica tanto en espacios del proyecto (GitHub, Issues, PRs) como en espacios públicos donde alguien esté representando al proyecto.

## Atribución

Este Código de Conducta está adaptado del [Contributor Covenant](https://www.contributor-covenant.org/), versión 2.1.

---

Al participar en este proyecto, aceptas cumplir con este Código de Conducta.
